# Tech Layoffs Data Cleaning & Analysis

## Overview

This project analyzes a dataset of technology-company layoffs using MySQL.

The project focuses on practical SQL skills including data cleaning, standardization, handling missing values, aggregation, grouping, joins, and basic exploratory analysis.

## Tools

- MySQL
- SQL

## Project Workflow

1. Created a staging table to work without modifying the raw dataset.
2. Identified possible duplicate records.
3. Standardized company names and industry values.
4. Cleaned country names.
5. Converted date values into a proper `DATE` format.
6. Standardized missing industry values.
7. Removed records with no layoff measurements.
8. Performed basic analysis using aggregation and grouping.

## Analysis

The SQL file includes analysis of:

- Total layoffs by industry
- Total layoffs by country
- Companies with the highest reported layoffs
- Layoff events by year
- Number of layoff records by industry
- Average percentage laid off by industry
